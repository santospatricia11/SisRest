# Sistema de Gerenciamento de Restaurante Estudantil - SisREST

## Descrição do Projeto

Este projeto foi desenvolvido como parte do Trabalho de Conclusão de Curso (TCC), com o objetivo de criar um sistema completo para gerenciar o restaurante estudantil. O sistema abrange desde o controle de pedidos e cardápios até a gestão de usuários e relatórios.

## Funcionalidades

- **Gestão de Usuários**: Administração de perfis de estudantes e administradores.
- **Cardápios**: Criação e visualização de cardápios semanais.
- **Pedidos**: Controle de pedidos e refeições consumidas pelos usuários.
- **Relatórios**: Relatórios sobre pedidos e consumo.
- **Segurança**: Autenticação de usuários com diferentes tipos de acesso.

## Testes Automatizados com Selenium e JUnit

### Estrutura dos Testes

O projeto inclui testes automatizados para garantir a qualidade do sistema:

- **Selenium**: Utilizado para testar a interface do usuário, simulando interações no navegador.
- **JUnit**: Utilizado para testes de unidade e integração no back-end.

### Pré-requisitos para os Testes

- **Java 17** ou superior
- **Maven** configurado
- **Google Chrome** (ou navegador de sua escolha)
- **ChromeDriver** (ou outro WebDriver)
